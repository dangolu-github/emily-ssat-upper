Analogies · Block A

Category: a kind of

Choose the pair that shows the same relationship as the pair in capitals.

  1. Name both meanings. Then write one specific connector sentence for the first pair.
  2. Keep the order. Read every option with the same connector in the same direction.
  3. Test all five. Same topic is not the same relationship; keep the pair whose sentence stays true.

Category: a kind of

  • What it is: the first word is one kind of the second. A tern is a kind of bird. A hypothesis is a kind of explanation.
  • Connector sentence: ___ is a kind of ___. Say it aloud for the pair in capitals, then for every option. If the sentence becomes false, the option is out.
  • Direction: specific → general (tern → bird) or general → specific (bird → tern). The answer keeps the same direction as the capitals.
  • Level: one step, not two. Beagle → hound is one step; beagle → animal skips a level.
  • Abstract categories count too: insight → understanding, rumor → statement, grueling → difficult (a kind of difficulty).
  • Not the same as: part–whole (a wing is part of a bird), characteristic (swift describes a bird), function (a bird flies), or two categories side by side (insect / arachnid: neither contains the other).

Words to know

  • Category words: kind, type, sort, variety, form; class, order, family, genus, species, breed; member, specimen, example, instance.
  • Science categories in this unit: mammal → animal; primate → mammal; conifer → tree; dwarf planet → planet-like body; hypothesis → explanation; tern → seabird → bird.
  • Tricky words: arachnid (spiders and scorpions: a group beside insects, not inside them); reptile / lizard (reptile is the larger group); conifer (a cone-bearing tree: pine, fir, spruce); primate (monkeys, apes and humans); fur, feather, scale (features, never kinds); mound, nest, hive (things built, never kinds).
